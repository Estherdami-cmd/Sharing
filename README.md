# Sharing — 위시리스트형 현물 나눔 매칭

기관이 "이 물건이 이만큼 필요해요"를 먼저 올리고, 개인이 사진 한 장으로 그 목표를 나눠 채우는 서비스입니다.

게시판에 물건을 올려두고 기관이 일일이 골라가는 방식(당나귀형)의 모니터링 부담과 한 기관이 싹쓸이해가는 허점을, 크라우드펀딩식 구조로 뒤집었습니다.

## 실행하기

```bash
npm install
```

```bash
npm run dev
```

http://localhost:3000 에서 열립니다.

## 화면 구성

| 탭 | 역할 |
|---|---|
| **진행률 게시판** | 기관들이 올린 요청과 현재 진행률을 한눈에 |
| **기부자 모드** | 사진 등록 → AI 인식 → 매칭 → 신청 (4단계) |
| **기관 관리** | 필요 물품 등록, 진행률 확인, 신청 수락/거절 |

`/foodbank` 로 직접 들어가면 기관 관리 화면만 뜹니다. 시연할 때 두 번째 창으로 띄워 기관 역할을 맡기면 편합니다.

## 기부자 4단계

1. **물품 등록** — 사진 업로드 → AI가 품목명·유통기한을 읽고 **나눔 가능 여부를 판독**. 유통기한이 지났으면 다음 단계로 못 넘어갑니다.
2. **매칭 확인** — 인식 결과를 수정하고, 이 물건이 가장 필요한 곳을 **필요도·거리·진행률** 순으로 추천받아 선택
3. **나눔 신청** — 수량·장소·가능 요일/시간대 입력 → **양쪽 모두 가능한 날짜만** 걸러서 추천
4. **신청 완료** — 상태 확인, 기부금 영수증 요청

## AI 인식에 대해

**현재 실제 Vision API를 쓰지 않습니다.** 목업이지만 랜덤이 아니라 결정적입니다:

1. 화면 1의 **데모 모드** 셀렉트로 원하는 품목을 직접 지정 (발표 중 원하는 분기를 재현)
2. 파일명에 키워드가 있으면 그걸 사용 (`milk_expired.jpg` → 우유, 유통기한 지남)
3. 그 외에는 파일 이름+크기 해시 → **같은 사진이면 항상 같은 결과**

실제 API로 교체하려면 `app/api/recognize/route.ts` 한 파일만 고치면 됩니다. 응답 형태(`itemName`, `category`, `expiryDate`, `shareable`, `reason`)만 맞추면 나머지는 그대로 동작합니다.

## 시연 시나리오

1. **진행률 게시판**에서 "성인용 기저귀 15/50개(30%)" 같은 요청들을 보여주기
2. **기부자 모드** → 데모 모드에서 `우유 (유통기한 지남)` 선택 → 인식
   → 빨간 **나눔 불가** 뱃지, 다음 버튼 비활성
3. 유통기한을 내년으로 고치면 → **즉시 초록 나눔 가능**으로 바뀌고 버튼 활성화
4. 데모 모드 `성인용 기저귀`로 다시 인식 → 다음
5. 매칭 화면에서 **필요도·거리·진행률** 확인. 지역을 바꾸면 순위가 재정렬됨
6. 수량 10개 입력 → "진행률이 50%가 돼요" 미리보기
7. 가능 요일/시간대 선택 → **AI 추천 날짜 받기**
   (기관 운영일과 안 맞으면 "두 분 모두 가능한 날이 없어요"가 뜸)
8. 신청 완료 → **기관 관리** 탭에서 `수락 (진행률 +10)` 클릭
9. **진행률 게시판**으로 돌아오면 30% → **50%**로 올라 있음

## 데이터 저장

모든 데이터는 **서버 메모리**(`lib/store.ts`)에 있습니다. 서버를 재시작하면 시드 데이터로 초기화됩니다.
DB가 없어서 설치 없이 바로 돌아가지만, 여러 명이 각자 실행하면 데이터는 공유되지 않습니다.

## 구조

```
app/
  page.tsx                  3개 탭 전환
  _components/
    NeedBoard.tsx           진행률 게시판
    DonorFlow.tsx           기부자 4단계 (핵심 화면)
    AdminPanel.tsx          기관 관리
    NeedProgress.tsx        진행률 바 (공용)
  api/
    recognize/              AI 인식 (목업)
    needs/                  기관 요청 등록·조회
    donations/              기부 물품
    match/[id]/             필요도·거리 기반 추천
    slots/[id]/             양쪽 가능 날짜 계산
    applications/           신청·수락·거절
  ui.ts                     공용 스타일
lib/
  rules.ts                  순수 규칙 (유통기한 판정, 거리, 샘플 데이터)
  store.ts                  인메모리 저장소 + 추천 로직
```
